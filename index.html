Introdução ao JavaScript

O que é JavaScript?

É uma linguagem de programação muito utilizada para criar aplicações interativas e sistemas de software.

Ele é responsável por:

  • Responder a cliques
  • Validar formularios
  • Atualizar conteudos
  • Buscar dados de API
  • Controlar o comportamento da aplicação

IMPORTANTE JavaScript não é Java. Apesar da semelhança nos nomes, são linguagens totalmente diferentes, com caracteristas e ecossistemas próprios

Curiosidades: Foi criado em apenas 10 dias.

O que da pra fazer com JS?

  • Frontend

    • Menu
    • Titulos
    • Animações

    • Dashboard
    • Aplicações com React, Vue, Angular, Astro e etc.
  • Backend

    • Autenticação
    • Processar requisições
    • Integrar com serviços e banco de dados
    • Moblie/Desktop
    • Criar aplicativos
    • React Native e Electron
